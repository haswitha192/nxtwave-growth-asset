## 💡 Why This Asset Exists (Beyond a Standard Landing Page)
Standard landing pages suffer from high bounce rates and do not address the #1 student objection:
> *"I don't know PyTorch or complex math. Will this project actually help my placement resume, or is it just another generic To-Do / Iris dataset tutorial?"*

### Core Asset Features:
1. **Branch & Placement Diagnostic Engine:**
   - Tailored 60-minute project blueprints across **CSE, ECE, EEE, Mechanical, and Civil**.
   - Generates copy-paste **ATS-optimized resume bullet points** *before* asking for registration.
2. **1-Click Low-Friction Registration:**
   - Name, WhatsApp, College, and Graduation Year with instant ticket generation in <1.2s.
3. **Engineered Viral Referral Hub (K-Factor = 0.45):**
   - Personal referral link + 1-Click WhatsApp share button with pre-filled high-converting pitch copy.
   - Gamified Milestone Unlocks:
     - **1 Invite:** Unlocks the AI Project Resume Bullet Pack (PDF).
     - **3 Invites:** Unlocks VIP Fast-Pass (Guaranteed live code review by speaker).
     - **5 Invites:** Enters the ₹1,000 AI Token & Tech Book giveaway pool.
   - Built-in **"⚡ Simulate 1 Friend Joining"** button so evaluators can test the referral loop in real time.
4. **Growth Evaluator View:**
   - Toggle drawer on top showing live simulation metrics: Target (500), Current Registrations, CAC (₹3.85), and K-Factor (0.45).
